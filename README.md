# Bol

YouTube Music ya YouTube ka link daalo. App synced lyrics, square cover, aur LRC file nikaalti hai.

Kotlin + Jetpack Compose. Gaana YouTube player se chalta hai (audio download nahi hoti).

## Android Studio

1. Is repo ko clone karo.
2. Android Studio mein **Open** karo.
3. Agar Gradle wrapper maange, use banne do (Gradle 8.11).
4. Phone ya emulator pe Run.

Android 10 (API 29) ya uske baad chahiye.

Share sheet se YouTube link seedha Bol mein bhi khul sakta hai.
